# Анализ клиентов банка

## Контекст
Банк располагает данными о клиентах и их транзакционной активности.
Для повышения эффективности программ лояльности и коммуникаций важно понимать,
как различается поведение клиентов и какие сегменты обладают наибольшим потенциалом.

## Цель анализа
- изучить структуру клиентской базы;
- проанализировать активность клиентов по ключевым признакам;
- выделить поведенческие сегменты;
- сформулировать практические рекомендации для бизнеса.

## Данные
Публичный датасет (Kaggle), содержащий информацию о клиентах и их операциях.

## Основные этапы анализа
- очистка и подготовка данных;
- exploratory data analysis (EDA);
- анализ распределений и корреляций;
- сегментация клиентов по уровню активности.

## Ключевые выводы
- выявлены группы клиентов с различным уровнем вовлечённости;
- определены сегменты с высоким потенциалом удержания и апсейла;
- предложены направления для персонализированных программ лояльности.

## Инструменты
Python, pandas, numpy, matplotlib, seaborn.
