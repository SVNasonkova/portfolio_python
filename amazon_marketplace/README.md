# Анализ данных Amazon Marketplace

## Контекст
Маркетплейсы оперируют большими объёмами данных о заказах, товарах и категориях.
Анализ этих данных позволяет выявлять сезонные эффекты, точки роста и
оптимизировать ассортимент.

## Цель анализа
- проанализировать структуру заказов маркетплейса;
- выявить сезонные и категорийные паттерны;
- определить наиболее активные сегменты;
- сформулировать рекомендации для развития бизнеса.

## Данные
Публичный датасет (Kaggle) с данными о заказах Amazon Marketplace.

## Основные этапы анализа
- подготовка и очистка данных;
- exploratory data analysis (EDA);
- анализ динамики и сезонности;
- исследование категорий товаров.

## Ключевые выводы
- выявлены категории с наибольшим вкладом в оборот;
- обнаружены сезонные пики активности;
- сформулированы рекомендации по ассортименту и фокусу на ключевые категории.

## Инструменты
Python, pandas, numpy, matplotlib, seaborn, plotly.express.

## Материалы
- Jupyter Notebook с анализом
- Презентация с итоговыми выводами (если применимо)
