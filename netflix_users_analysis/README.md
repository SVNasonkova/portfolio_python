# Анализ пользователей Netflix

## Контекст
Стриминговый сервис Netflix работает с большой пользовательской базой,
где ключевыми факторами успеха являются удержание подписчиков и понимание
их предпочтений.

## Цель анализа
- изучить демографические характеристики пользователей;
- проанализировать распределение подписок;
- выявить поведенческие паттерны;
- сформулировать продуктовые инсайты.

## Данные
Публичный датасет (Kaggle) с информацией о пользователях Netflix
(страна, возраст, тип подписки и др.).

## Основные этапы анализа
- предварительная обработка данных;
- exploratory data analysis (EDA);
- визуализация ключевых показателей;
- сегментация пользователей.

## Ключевые выводы
- выявлены различия в структуре подписчиков по регионам и возрастным группам;
- определены сегменты с повышенной ценностью для продукта;
- сформулированы идеи для дальнейшей персонализации и retention-стратегий.

## Инструменты
Python, pandas, numpy, matplotlib, seaborn, plotly.
